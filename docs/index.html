Install KISS Signer

beta firmware test wallets only

  1. Plug it in

    Connect the device by USB from a desktop. Chrome, Brave or Edge only — Safari and Firefox cannot talk to it.

  2. Install

    Tick the box, press the button, then pick the port when the browser asks. About a minute.

  3. Power cycle

    Unplug, wait three seconds, plug back in. Cold boot only. You land on FRUIT ISLAND.
