Safety model

The UI should say exactly what the signer can prove.

Passphrase is part of the wallet

Words alone can open an empty or decoy wallet. Words plus the right passphrase reveal the real one.

Unknown data stops signing

Unknown PSBT fields, hidden outputs, unreadable scripts, network mismatch, and change mismatch stop hard.

Descriptors over xpub ambiguity

The export carries fingerprint, path, script wrapper, and change branch without SLIP-132 guesswork.

Use it

Four flows, no mystery meat.

Create wallet

Camera entropy, dice entropy, word backup, quiz, passphrase twice, fingerprint check.

Receive

Native, nested, or legacy address type. Testnet sticks while you learn. Path is visible.

Export

Descriptor QR for a watch-only coordinator. The app can build transactions but cannot spend.

Sign

QR or SD PSBT in, every output shown, actual script type surfaced, signed PSBT or STOP out.

Commands

Copy, run, power-cycle.

Build

tools/build_release.sh

Find port

ls /dev/cu.usbmodem* 2>/dev/null || ls /dev/ttyACM*

Full flash

uvx esptool --chip esp32p4 -p <port> -b 460800 \
  --before default-reset --after no-reset write-flash \
  --flash-mode dio --flash-size 16MB --flash-freq 80m \
  0x2000  build-release/bootloader/bootloader.bin \
  0x8000  build-release/partition_table/partition-table.bin \
  0x10000 build-release/guition_kiss_bringup.bin
