KISS-SIGNER

Release check

Two questions, and they are not the same question. Does this file match the published release, and is the published release signed by the KISS key. The first one this page answers. The second one your own computer has to answer, and the reason why is at the bottom.

1. Does the file match

Drop kiss-signer-0.1.0-beta11.bin here. It is hashed on this page, in your browser. Nothing is uploaded, and this works with no network at all.

2. Is the release signed

One command, in a terminal, in the folder you downloaded:

gpg --verify SHA256SUMS.asc SHA256SUMS

It must say Good signature and show this fingerprint:

166A CBF3 7786 FCEA A694 96DE 886F 1BFE B84E F1C0

Check that fingerprint against a second source before you trust it. The repository, the release notes, and anywhere else the project publishes it. A key you only ever saw next to the file it signs proves nothing.

Why the signature is not checked here

Because this page came from the same place as the file. A page that checked its own download would be vouching for itself, and anyone who could replace the firmware could replace the page that approves it. The hash check above is safe to run here because you compare its answer against a number that is inside the signed manifest.

What this does and does not prove

Does: the binary is exactly what the key holder built, from a commit you can rebuild yourself.

Does not: that the device will only boot signed firmware. That is secure boot, a separate hardware step. A release signature protects the download. Secure boot protects the device.
