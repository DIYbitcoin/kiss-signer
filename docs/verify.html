Camera audit check

Drop the kiss-proof.bin your KISS Signer wrote to the card. This page hashes it and derives the 24 words, right here, offline. Both must match what the device showed.

The copy on the card already carries the hash the device claimed, so dropping the file is the whole check. That copy came from the device being audited, though. For an independent check, fetch this page from kkdao.github.io/kiss-signer/verify.html or the repository, on a computer you trust.

24 words from that hash

bit of the hash checksum bit

    These words are burned. They are a real seed, derived from a file that sits on the card in the open. Anyone holding the card can derive them too. They exist only to prove the device honest. Never use them for funds.

    What this page computes

    entropy  = SHA256(kiss-proof.bin)         a proof frame is 1,875,328 bytes
checksum = first 8 bits of SHA256(entropy)
words    = 24 x 11 bit slices of entropy + checksum, standard English list

    Prefer your own tools? shasum -a 256 kiss-proof.bin must equal the hash above, and any BIP39 tool fed that hash as entropy must produce the same words. The repository ships tools/verify_proof.py which does both in one command.
